# School Platform

Дипломный проект — веб-платформа для школ.

## О проекте

Платформа для школьников, учителей, родителей и администрации школы:
расписание, чаты, страницы предметов с учебниками и ДЗ, оценки,
посещаемость, аналитика.

**Обязательные требования:**
- Админ-панель
- Глобальный доступ по ссылке (не локально)

## Стек

- **Backend:** C# / ASP.NET Core
- **Frontend:** Blazor (TBD)
- **БД:** PostgreSQL
- **ORM:** Entity Framework Core + Npgsql
- **Realtime:** SignalR
- **Auth:** ASP.NET Core Identity + JWT
- **Инструменты:** Visual Studio 2022, VS Code, Docker, Git
- **Деплой:** Railway / Render + Neon (Postgres)
